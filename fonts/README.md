# Local appearance fonts

Downloaded from the Google Fonts CSS2 API on 2026-09-09, with Jost added on 2026-09-28.
Departure Mono v1.500 was added from its [official release](https://github.com/rektdeckard/departure-mono/releases/tag/v1.500)
on 2026-09-29. Each family retains its SIL Open Font License in LICENSE-<family>.txt.
Binary font data is unmodified. The Google Fonts filenames use a source-URL hash;
Departure Mono's filename records its release version.
The Google Fonts families include Latin and Latin Extended subsets; other scripts use
system fallbacks. Departure Mono's complete face also includes Cyrillic and Greek.
`fonts.css` retains subset Unicode ranges where applicable and uses swap.

Families: Source Serif 4 (400), IBM Plex Mono (400/500/600), Newsreader (400–600),
DM Sans (400–700, retained but unused), Jost (400–500), Montserrat (400–600), Courier Prime (400/700), VT323 (400),
Departure Mono (400), Fira Mono (400/500, retained as terminal fallback). Georgia is a system font and requires no download.

The homepage and coffee page link the shared definitions. Browsers request only
the font files used by the chosen appearance; there is no background preload of
other styles. Non-generative pages retain their existing font loading.
